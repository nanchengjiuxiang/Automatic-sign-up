# 报名接龙工具

Windows 桌面原型：预先录入活动、报名时间和字段映射，到点后用经过截图锚点校验的鼠标/键盘操作填写 QQ 小程序。

## 启动

需要 Windows 10/11、Python 3.10+、Tkinter，并安装依赖：

```powershell
python -m pip install -r requirements.txt
rapidocr download_models
python app.py
```

## 构建 Windows 安装包

面向其他用户分发时，使用 64 位 Windows 构建。准备 64 位 Python 3.10+，在项目根目录运行：

```powershell
& .\packaging\build.ps1
```

构建会把 OCR 运行库、模型和 `assets` 页面模板打进程序目录，再生成 `dist\报名接龙工具-Setup-1.0.0.exe` 单文件安装包。接收者安装后不需要安装 Python。程序资料保存在其 Windows 用户目录并由 DPAPI 加密；卸载程序不会删除该资料。

本地任务、资料和执行记录保存在 `%LOCALAPPDATA%\SignupChain\data.bin`，由 Windows DPAPI 按当前 Windows 用户加密。

在“执行记录”页可以点击“清理临时文件”，清理本软件数据目录里遗留的 `.tmp` 文件和 `temp` 子目录内容。清理不会触碰 Windows 临时目录，也不会删除报名资料、任务、运行记录或 OCR 模型。

## 当前自动化流程

1. 在软件里填写小程序名称、活动名称、精确报名开始时间。
2. 新任务预置“姓名、学号、学院、手机号”四个字段，用户可在报名任务中填入内容，也可从个人资料导入。字段名应与小程序报名页显示的标签一致；用户可增删改字段，预设字段可以多于小程序实际表单。
3. 打开桌面软件时会短暂切到 QQ，预检并绑定当前活动详情页，然后返回桌面软件；如果当时未打开目标页，可在 QQ 打开后点击“连接并预检 QQ 页面”。
4. 预检检查运行依赖、识别模板、QQ 窗口、窗口比例和活动详情页模板，保存绑定窗口的句柄与进程号；它不会填写或提交。软件会显示识别分数及待执行任务字段配置情况。
5. 报名任务页可以设置“未到开始时间时的自动重试时长”（1–600 秒，默认 30 秒）。到点后重新验证仍是已绑定窗口且页面仍符合活动详情页模板，再点击右下角“点我报名”。如果出现“接龙未到开始时间”弹窗，会按专用截图模板识别，点“我知道了”并确认弹窗消失、详情页恢复后立即重试；从首次检测到此弹窗开始计时，期间反复处理，进入填写页后停止重试，超时仍未进入填写页则停止并记录错误，不会继续循环。
6. 识别填写页后使用中文 OCR 读取表单字段标签，按标签匹配预填内容，不依赖固定字段顺序；预设字段没有出现在表单中时跳过。若识别到未配置的字段、无法匹配标签或必填字段映射缺失，软件停止且不提交。逐项检查填入区域有变化后才点击“提交报名”；仅在检测到“信息提交成功”时记为成功。

报名表默认勾选“不公开信息（仅我和发起人可见）”；当前流程保留小程序的默认隐私选择。

QQ 的 Windows UI Automation 树目前只暴露 Chromium 网页区域，没有暴露网页内部按钮和输入框。因此执行器使用截图模板校验活动页/填写页，通过 RapidOCR 识别字段标签和其纵向位置，再在对应输入行填写；不读取或记录已输入的个人信息。字段标签须与小程序显示文字相符；OCR 无法确定映射时不会提交。文本使用 Windows `SendInput` 的 Unicode 输入方式，支持中文字符。提交后再识别成功页；若未识别到，只提示人工核实且不自动重试。

图像识别模板位于 `assets/`，来自用户提供的活动页、成功页和“未到开始时间”弹窗截图。RapidOCR 模型需在安装后预下载，首次启动预检会加载 OCR 引擎。自动执行要求 QQ 小程序窗口保持可见，并保持接近截图的竖屏比例。活动页或小程序布局更新后，需要重新校准页面模板。报名开始到服务器确认成功的总耗时不受本机软件保证；进入填写页、识别标签、输入资料和提交可能超过 1 秒。

## 下一步验证

如果启动自动预检没有绑定成功，在 QQ 中打开目标活动详情页，然后点击“连接并预检 QQ 页面”。只有预检通过后再安排任务；每次任务执行仍会重新检查窗口和页面。该页面匹配可以确认详情页样式，不能自动读取活动标题，所以必须人工确认当前活动与任务名称一致。只读控件树检查只读取控件名称和 AutomationId；当前 QQ 的 UI Automation 树没有暴露小程序内部按钮或输入框，因此它不会列出报名表字段。
