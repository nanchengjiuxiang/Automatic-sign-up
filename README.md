# 报名接龙工具

报名接龙工具是一个 Windows 桌面程序，用于提前准备 QQ 小程序报名任务，并在预约时间尝试填写和提交报名表。程序通过截图模板确认页面状态，使用 RapidOCR 识别字段标签，再按字段名称填写预设内容。

自动化操作依赖 QQ、小程序页面布局、窗口状态和本机运行环境。使用前请阅读运行限制，并确认目标活动和报名字段配置正确。

## 用户指南

### 功能

- 创建和管理报名任务，包括目标小程序、活动名称、开始时间和报名字段。
- 管理个人资料，并将资料导入报名任务。
- 连接并预检 QQ 活动详情页；预检只读，不会填写或提交。
- 到预约时间后重新检查 QQ 窗口和页面，再尝试进入报名表。
- 对“接龙未到开始时间”提示按设定时长重试，默认 30 秒，可设置 1–600 秒。
- 使用中文 OCR 按页面标签匹配报名字段，字段顺序可以不同。
- 查看运行记录，并清理软件数据目录中的临时文件。

### 运行要求

- Windows 10 或 Windows 11
- 64 位 Python 3.10 或更新版本（仅从源码运行时需要）
- Tkinter（通常随 Windows 版 Python 提供）
- QQ 桌面版，以及已打开并显示在屏幕上的目标小程序活动详情页

### 安装与启动

普通用户可以运行发布的 `SignupDeskSetup.exe` 安装程序。安装后无需另外安装 Python。

开发者也可以直接从源码启动。请在项目根目录打开 PowerShell：

```powershell
py -3.10 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
rapidocr download_models
python app.py
```

如果系统没有 `py -3.10` 命令，请改用已安装的 64 位 Python 3.10 或更新版本创建虚拟环境。首次预检会加载 OCR 引擎，启动可能需要一些时间。

### 使用流程

1. 在 QQ 中打开目标活动详情页，并让 QQ 窗口保持可见。
2. 启动程序，在“报名任务”页点击“连接并预检 QQ 页面”。确认预检通过后再安排任务。
3. 新建任务，填写小程序名称、活动名称和报名开始时间。时间格式为 `YYYY-MM-DD HH:MM:SS`，且必须晚于当前时间。
4. 配置报名字段及对应的预填内容。字段名称应与报名表标签一致。新任务预置姓名、学号、学院、手机号，可按实际表单增删改，也可以从个人资料导入。
5. 设置遇到“接龙未到开始时间”提示后的重试时长（1–600 秒，默认 30 秒），保存任务并等待执行。
6. 在“执行记录”页查看识别、执行和提交结果。结果不确定时请人工检查 QQ 页面；程序不会自动重复提交。

### 任务执行与安全检查

- 预检会检查运行依赖、页面识别模板、QQ 窗口、窗口比例和活动详情页，并保存绑定窗口的句柄与进程号。预检不会填写或提交信息。
- 正式执行时会再次核对绑定窗口和页面。程序不会自动读取活动标题，请人工确认当前打开的活动与任务名称相符。
- 出现“接龙未到开始时间”弹窗时，程序会识别并关闭弹窗，确认活动详情页恢复后再试。计时从首次识别到该弹窗开始；达到设定时长仍未进入填写页就会停止。
- 程序使用 OCR 识别表单标签并匹配字段，不要求字段固定排序。未出现在页面的预设字段会跳过。遇到未配置字段、标签无法匹配、重复或位置不明确的字段，以及未配置的必填字段时，程序会停止且不会点击提交。
- 填写后会检查输入区域是否发生变化，再尝试点击“提交报名”。只有识别到成功页面才记录为确认成功；点击提交后无法确认时，会提示人工核实且不会自动重试。
- 报名表默认的“不公开信息（仅我和发起人可见）”选项会保留小程序当前默认设置。

### 运行限制

QQ 的 Windows UI Automation 树目前没有暴露小程序内部的按钮和输入框。程序使用 `assets/` 中的截图模板校验页面，通过 RapidOCR 识别表单标签和位置，再以鼠标、键盘输入操作页面；中文输入使用 Windows `SendInput` 的 Unicode 输入方式。

自动执行期间请保持目标 QQ 窗口可见，不要遮挡或切换其页面，并尽量保持与模板截图接近的竖屏窗口比例。若 QQ、小程序或页面布局更新，现有模板可能无法识别，需要重新校准模板。报名开始时间到服务器确认成功所需的总时长不受本机程序保证，整个过程可能超过 1 秒。

程序不会读取或记录已输入的个人信息。任务字段内容和个人资料保存在本机加密数据文件中。

### 本地数据与隐私

任务、个人资料及运行记录保存在：

```text
%LOCALAPPDATA%\SignupChain\data.bin
```

数据由 Windows DPAPI 按当前 Windows 用户加密。其他 Windows 用户通常无法解密此文件；卸载程序不会删除该数据。更换 Windows 用户或设备前，请自行妥善处理需要保留的数据。

“执行记录”页的“清理临时文件”仅清理软件数据目录内遗留的 `.tmp` 文件和 `temp` 子目录内容，不会清理 Windows 临时目录、报名资料、任务、运行记录或 OCR 模型。

## 开发者指南

### 技术与依赖

- Python、Tkinter：Windows 桌面界面和任务管理。
- uiautomation：检查 QQ 窗口及可访问的 Windows UI Automation 控件。
- OpenCV、Pillow、NumPy：截图处理和页面模板匹配。
- RapidOCR、ONNX Runtime：识别页面字段标签。
- Windows DPAPI：加密本地任务、资料和运行记录。

依赖版本范围见 [`requirements.txt`](requirements.txt)。项目针对 Windows 桌面环境编写，自动化和 DPAPI 功能不能在非 Windows 系统上正常运行。

### 源码结构

```text
app.py                           桌面界面、任务调度、本地加密数据
visual_automation.py             QQ 页面预检、截图识别、OCR 和输入执行
assets/                          活动页、填写页、弹窗和成功页识别模板
packaging/build.ps1              Windows 构建脚本
packaging/installer_bootstrap.py 安装程序入口
requirements.txt                 Python 运行依赖
*.spec                           PyInstaller 配置文件
```

### 构建 Windows 安装包

在 64 位 Windows 上准备 64 位 Python 3.10 或更新版本，在项目根目录运行：

```powershell
.\packaging\build.ps1
```

脚本会安装构建依赖、准备 RapidOCR 模型，使用 PyInstaller 先构建程序目录，再将其打包为单文件安装程序：

```text
dist\SignupDeskSetup.exe
```

可以通过环境变量 `SIGNUP_BUILD_PYTHON` 指定构建所用 Python 可执行文件的完整路径。构建依赖、程序目录和安装包分别位于 `.build-deps/`、`build/` 和 `dist/`；这些生成目录已列入 `.gitignore`。

### 页面模板与自动化维护

页面图像模板位于 `assets/`，用于识别活动详情页、填写页、未到开始时间提示和提交成功页面。QQ、小程序或窗口布局变更后，应重新采集并校准模板，再检查页面匹配和 OCR 字段定位是否仍符合预期。

修改视觉自动化时，应保留执行前的页面校验、字段名称匹配、必填字段保护、输入变化确认和成功页面识别。遇到无法确认页面状态或字段映射的情况，程序应停止，不要继续提交。

## 故障排查

- **预检未通过：**在 QQ 中打开目标活动详情页，确保窗口可见且接近模板的竖屏比例，再点击“连接并预检 QQ 页面”。
- **OCR 模型缺失或加载失败：**从源码运行时执行 `rapidocr download_models`，确认依赖安装成功后重新启动。
- **找不到报名字段或字段映射失败：**检查任务字段名称是否与页面标签一致，确认是否有未配置的必填字段，并查看 QQ 页面是否被遮挡或布局已改变。
- **点击提交后未确认成功：**人工查看 QQ 页面和运行记录；程序不会自动再次提交。

页面模板匹配只能确认页面样式，不能确认活动标题。正式执行前请人工核对 QQ 中打开的活动。
